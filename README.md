# 픽셀 경제 마을 - 웹 배포용 초안

학생 태블릿은 앱 설치 없이 브라우저에서 접속합니다. 서버는 Node.js + Express + Socket.IO입니다.

## 포함 기능
- Phaser 마을 화면, 태블릿 터치 방향키
- 실시간 최대 30명 입장 제한
- 일하기, 상품 구매/판매, 예금/출금, 주식 매매, 부동산 구매, 학생 송금
- 전자기기·식품·장난감/학용품 회사 창업, 제품 생산·판매, 영업이익 집계
- 회사 창업으로 등록된 종목만 거래하는 모의 주식 시장: 교사가 월~토 요일·시각과 턴당 진행 시간(5~180분)을 설정하고, 토요일 장 마감 시 수업을 종료해 최고의 CEO상을 선정
- 수업 종료 시 학생 성과와 시가총액·영업이익을 반영한 최고의 CEO상
- 교사용 PIN 화면: 접속자/잔액 보기, 뉴스 공지, 보너스 지급, 세율 설정

## 배포 전 필수 주의
- 이 코드는 수업용 프로토타입입니다. 영구 데이터베이스가 없으므로 서버가 재시작되면 게임 데이터가 초기화됩니다.
- 주가는 학생 매수·매도 수요, 기업의 누적 영업이익, 무작위 시장 변동을 이용하는 학습용 모의 모형입니다. 외부 거래소나 실제 주가와 연결되지 않으며 투자 성과를 보장하지 않습니다.
- 세율은 일부 현금 수입에만 반영되며, 임대료는 아직 구현되지 않았습니다.
- 교사 인증값은 서버에서 확인하며, 배포 시 환경변수 `TEACHER_PIN`에 별도의 값을 설정하세요.
- 기본 방 코드는 TOWN123이며 환경변수 `ROOM_CODE`로 변경할 수 있습니다.
- 학생 이름은 별명만 사용하고 실제 개인정보를 입력하지 마세요.
- 공개 배포 전에 교사/보호자 또는 학교 담당자가 보안 설정과 이용 약관을 확인해야 합니다. 미성년자는 계정 나이 제한을 우회하지 마세요.

## Render 배포 개요
1. 이 폴더를 GitHub 저장소에 올립니다(학교/보호자 허가를 받아 진행).
2. Render에서 New > Web Service를 선택하고 저장소를 연결합니다.
3. Runtime Node, Build Command `npm install`, Start Command `npm start`를 지정합니다.
4. 환경변수 `ROOM_CODE`와 교사만 아는 `TEACHER_PIN`을 설정합니다. 인증값은 화면이나 로그에 표시되지 않도록 관리하세요.
5. 배포된 HTTPS 주소를 학생들에게 공유합니다.

무료 호스팅은 절전/재시작/자원 제한이 있을 수 있으므로 30대 동시 접속은 반드시 사전 테스트하세요. 이 파일만으로 서버가 이미 인터넷에 배포되는 것은 아닙니다.

## 브라우저 자동 테스트

Playwright와 Chromium으로 실제 게임 페이지의 교실 생성, 4자리 코드 입장, 키보드 이동을 테스트하고, 대표 경제 거래와 30명 동시 접속 계약도 확인합니다. 유지해야 할 기능과 저장 방식 검토는 [기능 계약 문서](./docs/functional-contracts.md)를 참고하세요.

```bash
npm install
npx playwright install chromium
npm run test:e2e
```

테스트는 로컬 게임 서버를 자동으로 실행하고 종료합니다. 스크린샷은 `test-results/screenshots/pixel-town-game.png`, 브라우저/서버 오류 로그는 `test-results/`에 저장됩니다. 30명 테스트는 서버 Socket.IO 접속 한도를 검증하며, 호스팅 환경의 용량 측정은 별도로 해야 합니다. HTML 결과는 `npm run test:e2e:report`로 열 수 있습니다.
